# Kaggle Learn: Data Visualization — My Solutions

This repository contains my completed exercises and notes from the [Kaggle Learn: Data Visualization](https://www.kaggle.com/learn/data-visualization) course.  
The course focuses on using Python libraries to create clear, informative, and visually appealing plots — an essential skill for any data scientist.

---

## 📘 About the Course
The *Data Visualization* micro-course teaches how to turn raw data into insights using plots and charts.  
It covers a range of visualization techniques, from simple line and bar charts to more advanced plots that highlight relationships, distributions, and patterns in data.

---

## 🧑‍💻 What You’ll Find Here
- **Jupyter Notebooks** with my solutions to all course exercises.  
- **Clean, well-documented code** demonstrating best practices.  
- **Visual examples** of plots created with libraries such as **Matplotlib** and **Seaborn**.  
- Extended versions of some exercises, where I experimented with customizations and alternative visualizations.
